# Install or update Everyday

1. Open this repository's Releases page and choose v1.2.33.
2. Download Everyday-v1.2.33.apk from Assets. GitHub's automatic Source code ZIP
   contains this public help/download repository, not the private Android source.
3. Android 11 or newer is required. Compare the file's SHA-256 with release.json
   or SHA256SUMS.txt in the release assets if you want to check the exact download.
4. Open the APK on your phone and review Android's installation decision. Allow
   installation for your chosen browser/file manager only if you trust the source.
5. If Everyday is already installed, install as an update. Do not uninstall/clear
   records first; take your manual backups before updating. Keep the same signing
   identity for compatible future updates.
6. Open Everyday. Existing profile/data should remain. Help is under More and About.

The v1.2.33 APK is a debug-signed personal-test prototype without an activation
key gate. Private release downloads require repository access; downloaded files can still be copied by recipients;
source privacy and proprietary terms do not add technical copy protection.
