# Everyday — private downloads and help

Keep this repository PRIVATE. Everyday v1.2.33 requires Android 11 or newer.
Invited collaborators can download the APK and help ZIP from Releases → v1.2.33.
They do not need access to the separate private Android source repository.

- About: ABOUT.md
- License: LICENSE
- Installation: INSTALL.md
- Version and APK checksum: release.json

For interactive help, download Everyday-help-v1.2.33.zip from the private release,
extract it and open index.html or guide/user-guide.html. Search, expandable chapters,
previous/next and theme controls work locally. GitHub's file viewer shows HTML
source rather than running the guide. No public website is needed.

Leave GitHub Pages disabled. A private repository does not by itself make a Pages
site private. The root proprietary notice and all third-party notices are retained.
